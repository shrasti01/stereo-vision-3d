Stereo Vision 3D Distance Measurement System

This project implements a complete stereo computer vision pipeline for estimating real-world distances of objects from stereo image pairs using Python and OpenCV. The system performs camera calibration with chessboard patterns to determine intrinsic and extrinsic parameters, stereo rectification to align epipolar lines, and Semi-Global Block Matching (SGBM) for dense disparity computation. The core depth equation Z = (f x B) / d is used to convert disparity maps to depth maps, where Z is depth, f is focal length, B is baseline distance between cameras, and d is disparity. The system supports region-of-interest selection for measuring distances to specific objects and provides comprehensive accuracy evaluation including Mean Absolute Error, Root Mean Square Error, and relative error analysis. This project demonstrates practical applications of stereo vision in robotics, autonomous navigation, and 3D scene understanding without relying on deep learning methods, making it suitable for real-time embedded systems.
